       - `Brand`: id, name, slug, logo_url, website_url, description, is_verified
       - `Category`: id, name, slug, description, icon, display_order
       - `Product`: id, brand_id, category_id, name, slug, description, image_url, is_active, brand (nested), category (nested)
       - `ProductVariant`: id, product_id, variant_name, slug, mrp_inr, net_weight_g, serving_size_g, calories_kcal, protein_g, total_fat_g, saturated_fat_g, trans_fat_g, cholesterol_mg, total_carbs_g, dietary_fiber_g, total_sugars_g, added_sugars_g, sodium_mg, ingredient_list, allergens, dietary_tags, primary_protein_source, protein_tier, has_added_free_form_aminos, cost_per_g_protein, protein_density_pct, true_net_carbs_g, image_url, is_active
       - `VariantRedFlag`: id, variant_id, flag_type, flag_severity, flag_label, flag_description, matched_ingredient, ins_number
       - `RedirectLink`: id, variant_id, platform, url, platform_price_inr, price_last_checked
       - `ProductWithVariants`: Product with variants[], brand, category nested

    2. `src/lib/constants.ts`: Export category definitions, sort options, tier labels and descriptions, platform display names, and color tokens for tiers/severities.

    3. `src/lib/utils.ts`: Formatting utilities:
       - `formatPrice(price: number)`: Returns `₹1,499` formatted string
       - `formatPricePerGram(price: number)`: Returns `₹7.50/g`
       - `formatPercentage(pct: number)`: Returns `37.7%`
       - `formatWeight(g: number)`: Returns `52g` or `1kg`
       - `computePer100g(value: number, netWeightG: number)`: `(value / netWeightG) * 100`
       - `cn(...classes)`: Conditional classname joiner

    4. `src/lib/redirect.ts`: Implement the redirect URL builder from Section 6.3 of the architecture:
       - `buildRedirectUrl(platform, ctx)`: Platform-specific URL construction
       - `getPriceDisplay(platform, storedPrice)`: Returns `{ type: 'stored', price }` or `{ type: 'check_local' }`
       - Amazon URLs append affiliate tag parameter
       - Quick-commerce URLs use search query format
  </action>
