       - **Dietary Tags**: Checkbox list (Vegan, Vegetarian, Keto, Gluten-Free, Organic, No Added Sugar)
       - **Allergens (Exclude)**: Checkbox list (Milk, Soy, Gluten, Tree Nuts, Eggs, Peanuts)

    2. `SortDropdown.tsx`: Sort option selector:
       - "Cost per Gram (₹/g) — Low to High" (default)
       - "Protein Density — High to Low"
       - "Price — Low to High"
       - "Price — High to Low"
       - "Newest First"
       - Visual indicator for active sort
       - Dropdown with smooth open/close animation

    3. `useFilters.ts`: Custom hook managing filter state:
       - Reads and writes to URL search params (`useSearchParams`)
       - Constructs Supabase query with:
         - Category filter: `eq('category_id', id)`
         - Tier filter: `in('protein_tier', tiers)`
         - Dietary tags filter: `overlaps('dietary_tags', tags)`
         - Allergen exclusion: `not.overlaps('allergens', excluded)`
         - Zero red flags: LEFT JOIN with count check
         - Sort: `order(column, { ascending })` with the selected column
       - Returns `{ filters, setFilter, clearFilters, sortBy, setSortBy, query }`
       - Debounced filter application for performance

       - Expandable search bar with magnifying glass icon
       - Debounced input (300ms) for live autocomplete suggestions
       - Autocomplete dropdown: Shows top 5 matching products with brand name, product name, and ₹/g metric
       - "Enter" or click suggestion navigates to `/search?q={query}` or directly to `/product/[slug]`

    2. `useSearch.ts`: Custom search hook:
       - Accepts query string and returns matching products
       - Uses Supabase `.textSearch()` or `.ilike()` with `%query%` pattern on products.name
       - Alternatively uses PostgreSQL trigram similarity: `similarity(name, query) > 0.3`
       - Searches across product names, brand names, and variant names
       - Returns sorted by relevance (similarity score) then by cost_per_g_protein
       - Debounced to avoid excessive queries

    3. `/search/page.tsx`: Full search results page:
       - URL parameter: `/search?q=whey+protein`
       - Search bar pre-filled with query
       - Results grid using ProductCard components
       - "Showing N results for 'whey protein'"
       - Empty state: "No products found for '{query}'" with suggestions
       - SSR: Initial results fetched server-side for SEO
