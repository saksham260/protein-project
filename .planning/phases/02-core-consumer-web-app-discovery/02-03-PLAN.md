  <files>protein-web/src/app/product/[slug]/page.tsx</files>
  <read_first>implementation_plan.md (Section 6.2), protein-web/src/lib/supabase/server.ts, protein-web/src/types/product.ts</read_first>
  <action>
    Build the Product Detail Page route:

    1. **Static Generation**:
       - `generateStaticParams()`: Query all active products from Supabase, return `{ slug }` for each.
       - `export const revalidate = 3600` (1 hour ISR).

    2. **SEO Metadata**:
       - `generateMetadata({ params })`: Fetch product by slug.
       - Title: `"{Product Name} by {Brand} – Nutrition, Red Flags & Price | Protein Discovery Engine"`
       - Description: `"{Product Name}: {protein_g}g protein, ₹{cost_per_g}/g, {density}% density. {flag_count} red flags. Compare on Amazon, Blinkit, Zepto."`

    3. **Data Fetching**:
       - Server component fetches complete product data in a single query:
         - Product with brand and category (joined)
         - All variants with nutrition columns
         - Red flags for each variant (nested)
         - Redirect links for each variant (nested)
       - Supabase query: `from('products').select('*, brand:brands(*), category:categories(*), variants:product_variants(*, red_flags:variant_red_flags(*), redirect_links:redirect_links(*))').eq('slug', slug).single()`

    4. **Page Layout**: Renders `<ProductDetail>` component with fetched data.

    5. **404 Handling**: If product not found, call `notFound()` from `next/navigation`.
  </action>
  <verify>grep -q "generateStaticParams\|generateMetadata" protein-web/src/app/product/\\[slug\\]/page.tsx</verify>
  <acceptance_criteria>
    - generateStaticParams returns slugs for all active products
    - generateMetadata produces product-specific title and description
    - Page fetches product with all variants, red flags, and redirect links in one query
    - 404 is handled with notFound() for missing products
    - ISR revalidate = 3600
  </acceptance_criteria>
