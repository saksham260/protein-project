         - `interactive`: Launches interactive single-product wizard.

         - `--dry-run`: Forces dry-run mode without live DB calls.
       - Interactive Flow:
         - Step 1: Prompt for source: [1] Shopify URL, [2] Manual entry.
         - Step 2: Fetch or prompt data.
         - Step 3: Run metrics computation, red-flag detection, and tier classifier.
         - Step 4: Render rich terminal preview table:
           - Computed Metrics (₹/g, Density %, Net Carbs).
           - Red Flags (Status, Badges, INS numbers).
           - Protein Profile (Primary source, Tier 1-4, Amino spiking alert).
         - Step 5: Ask user confirmation before upload: `? Upload to Supabase? [Y/n]`.
         - Step 6: Prompt for optional redirect URLs (Amazon, Blinkit, Zepto, D2C).
         - Step 7: Invoke `SupabaseUploader` and report status.
       - Batch Flow:
         - Iterates through input JSON, computes metrics/flags for each entry, validates with Pydantic, and calls uploader.
    2. Create `protein-etl/tests/test_cli.py`:
       - Test CLI argument parsing (`batch --dry-run`).
       - Test end-to-end processing of a sample product JSON in dry-run mode.
