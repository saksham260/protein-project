       - Tier 1: "Whey Protein Isolate", "Whey Protein Hydrolysate", "Hydrolyzed Whey", "Micellar Casein Isolate".
       - Tier 2: "Whey Protein Concentrate", "Milk Protein Concentrate", "Calcium Caseinate", "Casein", "Egg White Protein", "Egg Albumin".
       - Tier 3: "Pea Protein Isolate", "Pea Protein", "Brown Rice Protein", "Soy Protein Isolate", "Hemp Protein".
       - Tier 4: "Collagen", "Hydrolyzed Collagen", "Gelatin", "Wheat Gluten", "Vital Wheat Gluten", "Soy Protein Concentrate".
    2. Create `protein-etl/src/engine/protein_tier.py`:
       - `classify_protein_profile(ingredients: list[str], red_flags: list[RedFlagItem]) -> ProteinProfile`:
         1. Identify all protein sources appearing in the ingredient list by position.
         2. Set `primary_protein_source` to the canonical name of the FIRST protein source found in the deck (reflecting descending weight order).
         3. Check if any amino spiking red flag exists. If yes, mark `has_added_free_form_aminos = True` and force tier to Tier 4.
         4. Otherwise, classify tier by the **lowest-quality protein source present** (weakest-link rule: Tier 4 > Tier 3 > Tier 2 > Tier 1).
         5. If no recognized protein source is found, default to "Unknown / Unclassified".
    3. Create `protein-etl/tests/test_protein_tier.py` testing:
       - Pure Whey Isolate -> Tier 1.
       - Whey Isolate + Whey Concentrate blend -> Tier 2.
       - Whey Isolate + Collagen blend -> Tier 4 (weakest-link rule).
       - Plant blend (Pea + Brown Rice) -> Tier 3.
       - Amino-spiked blend (Whey + added Glycine) -> Tier 4 with `has_added_free_form_aminos = True`.
  </action>
